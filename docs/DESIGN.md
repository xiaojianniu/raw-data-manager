# 实验档案界面规范

实施依据为已批准的产品计划及 `design-concept.png`，不要求另行审批。

- 白底 #fff，侧栏 #f5f7fa，正文 #182b3a，次要文字 #697987，边框 #e4e9ef，强调 #117a70。6px 圆角，无渐变或装饰图。
- Windows 系统字体：Segoe UI、Microsoft YaHei UI、sans-serif；正文和控件 14px，标题 25px，辅助信息 12px。
- 左侧类型导航，中间检索表格，右侧选中实验详情概览；实验完整编辑用抽屉或展开详情。
- 导航：全部实验、WB、共聚焦、鼠尾鉴定、其他实验、已归档、资料库与备份。
- 主要操作：导入文件夹；搜索实验、样本、鼠号、靶标或文件名；课题与日期筛选；查看详情；导出实验。
- 详情页签：基本信息、样本与泳道（随类型调整）、文件、记录历史。
- 概念图的所有数据均为示例；实际程序首次启动空库，不植入虚构实验结果。
- 必要扩展界面：首次选择资料库、导入分类/分配向导、结构化记录表格、文件关联、导入进度/重试、备份/恢复。沿用同一套输入框、表格和按钮。
- 相比概念图的功能性差异：窄窗口按顺序堆叠面板；日期显示起止输入框；长路径与样本表允许横向滚动；实际文件计数来自数据库。

图像为内置 imagegen 按已确认需求生成，完整生成简报保留在本任务工具记录中。用户已授权实施，无概念审批阻塞。
