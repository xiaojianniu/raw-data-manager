# 实验档案 · Windows 个人版

本工具在本机保存实验文件及记录，不需要登录或上传数据。首次启动是空资料库。

## 安装与首次使用

1. 双击 `LabArchive-Setup-1.0.0-x64.exe`，按安装向导选择安装位置。安装后从“实验档案”快捷方式启动。
2. 选择一个空文件夹创建资料库，或打开已有的实验档案资料库。建议位置为 `C:\LGR\实验数据管理库`。不要把仪器原数据目录直接当作资料库。
3. 资料库与程序安装目录独立。升级或卸载程序不会删除资料库。运行不需要 Node.js、Python 或其他开发工具。

## 导入实验

点击“导入文件夹”，也可以把文件夹或文件拖进窗口。扫描计算文件哈希，大目录需要等待；此时先不要关闭程序。

- 核对文件角色：仪器原文件、导出图、处理结果、实验记录、汇总材料、待确认。无法确认时保留“待确认”。文件扩展名仅能辅助判断，不能证明生物学用途。
- 填写实验名称、类型、课题、日期、标签等。未知日期可以留空；软件不会用修改时间替代实验日期。
- 每个文件可以分配到本次新建实验或已有实验。批量设置作用于所有勾选文件；筛选列表不会自动取消其他文件的勾选。
- 相同内容提示不会自动删除或合并文件。再次导入会创建独立副本，保留各次来源关系。
- 点击“确认导入”后开始复制和 SHA-256 校验。只有全批成功，实验及其文件才会显示为已归档完成。原目录保持不变。
- 取消、失败或中断的任务可在“资料库与备份”重试。如果源文件已经改变，请重新扫描。失败副本保留在资料库的 `.staging` 或未提交的 `originals` 子目录，不作为成功资料显示；请勿在任务进行时手动处理这些目录。

扫描不进入目录联接或符号链接，也不从资料库内部重新导入。ZIP 作为原附件保存，不自动解压。正在采集或保存的文件应待原软件保存完成后再导入。

## 实验记录

点击实验，再点击“查看详情”。“保存修改”保存基本信息、记录和样本表；“记录历史”保留修改前后内容。

- **WB**：记录靶蛋白、内参、抗体、膜信息和实际泳道；Marker、曝光轮次和生物重复应按实际情况填写，软件不会根据文件名推定。
- **共聚焦**：记录样本、分组、生物重复、视野、通道和采集参数；原容器与导出图可以建立关联。
- **鼠尾鉴定**：先建立动物标识，再在不同实验或复测行中选择同一个标识。相同鼠号可以对应不同动物，列表中的短 ID 用于区分。记录取样日期、目标基因、引物、预期条带、泳道、对照、人工判定和复核状态。判定结果与复核状态分开，不自动判读图像。
- **其他实验**：使用通用样本表、参数、标签、备注和附件。

从 Excel 复制矩形单元格后，在样本表的起始单元格粘贴，可自动增加行。请先核对列顺序；鼠号关联使用下拉选择或明确的动物内部 ID，不会仅凭同名自动关联。空值按粘贴表格保留。

“复用最近参数”只带入当前类型的可复用参数，不带入旧的样本、动物、结果或备注。修改实验类型前，界面会要求核对已有记录，避免把另一类实验的数据直接当作当前类型。

## 文件预览、关联和处理

常规 JPG、PNG、TIFF 可在工具内查看；多页 TIFF 可翻页。显示图经过缩放，不用于灰度定量。超出解码范围、损坏或不支持的格式会显示原因，归档件仍保留。

SCN/MSCN、CZI、OIR、LIF 等仪器文件，以及 Office、PDF、ZIP 等附件，通过“打开工作副本”交给系统关联的软件；需要电脑已安装相应软件。未关联时会打开工作副本所在文件夹。

工作副本包含同一导入批次的伴随文件，维持原有目录关系，保存在程序用户数据目录的 `working-copies`。外部编辑不会回写归档件。保存结果后重新导入到原实验，标记为“处理结果”，并在“文件”页关联其来源。文件关系不自动推断。

## 检索与导出

搜索支持实验名称、课题、标签、靶标、样本、鼠号、记录内容及文件名；可按类型、课题和日期组合筛选。“已归档”只隐藏实验，可随时恢复，不删除文件。

“导出实验”生成独立文件夹，包含：

- `files/`：按导入批次保存的文件副本，名称及相对目录保留。
- `metadata.json`：完整实验信息、样本记录、动物标识、文件关系及历史。
- `records.csv`、`files.csv`：可由 Excel 打开的记录和文件清单。
- `manifest.json`、`SHA256SUMS.csv`：文件大小和校验值。
- `README.md`：简要说明及实验备注。

这些是带校验清单的文件夹包，不是 ZIP。源路径也记录在元数据中，向他人分享时请先检查是否适合包含这些信息。

## 完整备份与恢复

在“资料库与备份”点击“创建完整备份”，选择资料库之外的位置，建议另一块磁盘。备份包含所有成功归档文件、SQLite 一致快照、样本、动物、关系和历史。预览缓存、可编辑工作副本和失败暂存文件不包含在完整备份中。

恢复时选择包含 `backup-manifest.json` 的备份目录，再选择目标父目录。软件在新文件夹中恢复并检查文件哈希、数据库及关联，成功后切换到恢复的资料库；不会覆盖现有资料库。恢复失败的 `.partial` 目录不会作为成功库打开。

归档复制不等于跨磁盘备份。本版本没有自动定时备份；请在关键批次整理后手动备份。搬迁资料库时，先关闭程序，再完整复制资料库目录，重新选择打开；不要只复制正在使用的 SQLite 主文件。

## 首版边界

不包含 WB 灰度分析、共聚焦定量、自动基因型判读、繁育排程、多人协作或云同步。专有仪器容器不会被自动转换。文件大小的实际可处理范围还取决于磁盘空间，首版主要验收为代表性小批次；超大库的长时间负载尚未验证。

安装包为本地构建，未申请商业代码签名。实际版本、测试范围和未完成的真实样例验收见本机交付包中的 `docs/验收记录.md`；该记录包含本机路径，不随 GitHub 源码仓库上传。
